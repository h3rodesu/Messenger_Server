# Messenger Server

Серверная часть приложения-мессенджера, реализованная на языке C++. Проект предоставляет базовый функционал для многопоточной обработки клиентских подключений, маршрутизации сообщений и взаимодействия с базой данных.
 Исходный код клиентского приложения доступен в репозитории https://github.com/h3rodesu/Client_For_Messenger

## Технологический стек
* Язык программирования: C++20 (или выше)
* Сетевое взаимодействие: Системные сокеты, протокол HTTP
* Система сборки: CMake, MSBuild (Visual Studio)
* Библиотека libpqxx https://github.com/jtv/libpqxx?ysclid=mud2d0y3fn891758217
* Менеджер пакетов: vcpkg

## Структура проекта
* main.cpp - точка входа в приложение, инициализация и запуск сервера.
* ChatServer.h / .cpp - основной модуль сервера. Управляет жизненным циклом приложения, принимает новые подключения и маршрутизирует данные.
* ThreadPool.h / .cpp - реализация пула потоков. Обеспечивает параллельную обработку запросов от клиентов без блокировки основного потока выполнения.
* SafeSocket.h - инкапсуляция работы с системными сокетами для безопасного управления сетевыми соединениями.
* HttpRequest.h / .cpp - парсер и обработчик входящих HTTP-запросов.
* DataBaseManage.h / .cpp - модуль взаимодействия с базой данных для сохранения истории сообщений и проверки данных пользователей.

## Сборка и запуск

### Требования к окружению
* Компилятор с поддержкой стандарта C++20 или выше 
* CMake версии 3.15 или выше
* Установленный менеджер пакетов vcpkg (проект использует манифест vcpkg.json)

### Сборка через консоль (CMake)
Выполните следующие команды в терминале из корневой папки проекта:

```bash
mkdir build
cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=[путь_до_vcpkg]/scripts/buildsystems/vcpkg.cmake
cmake --build . --config Release
```
